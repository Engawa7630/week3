## 练习10：虚拟环境的作用

### 虚拟环境是什么？
虚拟环境是一个独立的 Python 运行环境，每个环境有自己的 Python 解释器和包目录。

### 为什么需要虚拟环境？
1. **隔离依赖**：不同项目可以使用不同版本的包，避免冲突
2. **可重现性**：通过 requirements.txt 精确记录依赖版本
3. **权限安全**：不需要 sudo 权限安装包
4. **清理方便**：删除虚拟环境目录即可清理所有包

### 观察结果
- 激活前：python 路径为（系统路径）
- 激活后：python 路径为（虚拟环境路径）
- 在虚拟环境中安装的包只存在于该环境中
- 退出虚拟环境后，之前安装的包不可用

### 实际应用场景
场景1：开发多个项目
每个项目有独立的虚拟环境，互不干扰。

场景2：部署到生产环境
在服务器上创建虚拟环境，只安装生产所需的依赖，避免不必要的包占用空间或引入安全风险。

场景3：实验新版本
在虚拟环境中尝试升级某个包到最新版，如果出现问题，直接删除虚拟环境即可，不影响全局。
